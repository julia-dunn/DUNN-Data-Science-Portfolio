# Data Science Portfolio

## Purpose

The goal for this portfolio is to house the comprehensive data science projects that I will complete throughout this upcoming semester in my Introduction to Data Science course. This includes, but is not limited to, data visualization, data tidying, and machine learning development. Beyond that, I hope to demonstrate a variety of concrete skills related to the industry of data analytics, data science, and data engineering. With each of these projects, I will demonstrate the value I bring to a future employer, the creativity with which I approach problems, and the technical skills I have to solve them.

## Projects

### [What is there to listen to on Spotify?](https://github.com/julia-dunn/DUNN-Data-Science-Portfolio/tree/main/basic_streamlit_app_2)
- Description: This app is essentially an exploratory data analytics dashboard, where you can learn about important relationships between numerical and categorical variables. Here, we explore a dataset of over 100,000 songs on spotify. Check out this user-interactive platform and generate visualizations yourself!
- Technical skills: Pandas, Matplotlib, Seaborn, Streamlit
