# Data Science Portfolio

## Purpose

The goal for this portfolio is to house the comprehensive data science projects that I will complete throughout this upcoming semester in my Introduction to Data Science course. This includes, but is not limited to, data visualization, data tidying, and machine learning development. Beyond that, I hope to demonstrate a variety of concrete skills related to the industry of data analytics, data science, and data engineering. With each of these projects, I will demonstrate the value I bring to a future employer, the creativity with which I approach problems, and the technical skills I have to solve them.

## Projects

### [What is there to listen to on Spotify?](https://github.com/julia-dunn/DUNN-Data-Science-Portfolio/tree/main/basic_streamlit_app_2)
- Description: This app is essentially an exploratory data analytics dashboard, where you can learn about important relationships between numerical and categorical variables. Here, we explore a dataset of over 100,000 songs on spotify. Check out this user-interactive platform and generate visualizations yourself!
- Technical skills: Pandas, Matplotlib, Seaborn, Streamlit
- This emphasizes the importance of data visualization, clarity, and accessibility. I built valuable skills with respect to user interaction and data manipulation.

### [Tidy Data Project 2](https://github.com/julia-dunn/DUNN-Data-Science-Portfolio/tree/main/TidyData-Project)
- Description: I created this Jupiter Notebook to further develop my skills in tidying data such that it can be analyzed and understood logically. This notebook's pivot tables and visualizations push beyond my first Tidy Data Project (Federal Research and Development Budgets) because the categorical data forces a level of creativity. This is a cumulation not only of data tidying principles and methods, but also of how to analyze and visualize neat data represented in dataframes. The goal of this project was to organize an external dataset, which contained information regarding 2008 Olympic medalists for both men and women.
- Technical skills: Pandas, Matplotlib, Seaborn
- This project emphasize the important of clean and coherent data for further data manipulation. The steps taking to tidy the dataset and construct pivot tables are non-trivial.

### [Choosing a Regression Model](https://github.com/julia-dunn/DUNN-Data-Science-Portfolio/tree/main/MLStreamlitApp)
- Description: This app can be used to create both linear and logistic regression models of datasets with primarily numerical variables. It walks the user through the process of cleaning data (on a low level), selecting the type of regression that makes sense, and choosing variables and target features that fit the requirements of the specified model. Most importantly, the user is pushed to think critically about if the models can be applied to their data. It is entirely possible for beginner data analysists, such as sutdents like myself, to act based on assumptions on their data that are deeply flawed. This app thinks deeply about if and when those assumptions can be applied, and then demonstrates the result of hyper-parameter fine-tuning once the assumptions have been made.
- Technical skills: Machine Learning, Linear Regression, Logistic Regression, SciKitLearn, Seaborn, Streamlit, Statstmodels
- This project emphasizes the importance of considering assumptions in data analytics and machine learning. Making sure your dataset can be modeled with a specific strategy is just as important as the modeling itself.
- Additionally, it builds on the previous projects by implementing tidy data AND streamlit syntax to create a user friendly data analysis dashboard.
